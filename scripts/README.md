# Scripts

This directory is reserved for reviewed helper tools. Planned categories include:

- local Puppet Agent and Git bootstrap;
- Puppet Server bootstrap;
- repository and syntax validation;
- safe local no-op and apply execution;
- r10k deployment helpers;
- status and diagnostics for the configuration-management platform itself.

The initial commit contains no executable scripts. Their behavior, supported operating systems, privilege model, logging, error handling, and rollback expectations will be designed before implementation.
