# sasd-role

Complete node roles for the SASD Puppet control repository:

- `baseline`
- `managed_agent`
- `server`
- `development`
- `container_host`
- `puppet_server`

Milestone 8 retains platform evidence to every role and expands eligible central
agent platforms to AlmaLinux 9 and Rocky Linux 9. The `puppet_server` role is
still operated only on Debian 12 and Ubuntu 24.04.
