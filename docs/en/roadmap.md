# Roadmap

## Completed

- Milestones 1–8: foundation, central service, operations, lifecycle, cross-platform agents, and production assurance.
- Milestone 9: OpenJDK 17/Maven and PHP command-line SDK profiles.
- Milestone 10: .NET 10 LTS SDK profile with explicit Debian repository trust and distribution-feed operation on Ubuntu/EL9.

## Candidate stepstones after 0.10.0

1. Enable Hiera eyaml only for a concrete secret-consuming profile after key custody and recovery tests.
2. Test a full service-level CA and encrypted-data restore on an isolated replacement server.
3. Validate .NET arm64 package sources before expanding the role architecture allowlist.
4. Evaluate EL10 agents only after Puppet and application-package validation.
5. Evaluate a second compiler only when measured load or availability requirements justify it.
