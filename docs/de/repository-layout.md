# Repository-Struktur

Wichtige Milestone-3-Pfade sind `site.pp` für die Klassifizierung, `data` für Hiera, `site-modules` für eigenen Puppet-Code, `modules` für von r10k erzeugte Abhängigkeiten, Server-/Agent-/CA-Skripte unter `scripts`, Konfigurationsbeispiele, ein optionales systemd-Beispiel, Tests sowie die parallele englische und deutsche Dokumentation.
